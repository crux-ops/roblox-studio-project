## 🛡️ ANTI-CHEAT MUTAKHIR - 5 LAYER DEFENSE (WAJIB IMPLEMENT SEMUA!)

Ini adalah bagian **PALING PENTING**. Game tanpa anti-cheat = mati dalam 1 minggu karena exploiter.


### LAYER 2: REMOTE VALIDATION (Middleware - Tiap RemoteEvent)
Setiap Remote HARUS lewat validasi berlapis di `RemoteValidator.lua`:

```lua
-- Pseudo - WAJIB IMPLEMENT:
function RemoteValidator:Validate(player: Player, remoteName: string, ...: any): (boolean, string?)
    -- 1. Type Check: pastikan tipe data sesuai (string bukan table, number bukan NaN/inf)
    -- 2. Whitelist: itemId harus ada di PlantConfig, tidak bisa ngarang
    -- 3. Rate Limit: token bucket per player per remote (misal PlantHarvest max 5x/detik)
    -- 4. Cooldown: weapon/steal punya cooldown server-side
    -- 5. Ownership: player harus punya item/plot yang diklaim
    -- 6. Distance Check: jarak player ke target < MAX_DISTANCE (anti remote steal dari jauh)
    -- 7. State Check: Day phase tidak bisa steal, Night phase baru bisa
    -- Return false jika GAGAL, dan log ke EvidenceLocker
end
```

**Daftar Remote yang harus dilindungi:**
- `HarvestPlant` -> cek ownership plot, plant sudah matang (server timer, bukan client timer!), rate limit
- `BuySeed` -> cek currency di server ledger (bukan leaderstats!), cek stock
- `StealPlant` -> cek Night Phase aktif, jarak, target plot tidak punya shield, cooldown 60 detik
- `TradeRequest` -> cek kedua player punya item, anti dupe, confirmation UI
- `FusePlants` -> cek player punya 3 plant yang di-fuse, random result di SERVER (bukan client!)
- Semua remote lain = validasi yang sama.

### LAYER 3: SANITY CHECKS & SERVER LEDGER (Anti Economy Exploit)
```lua
-- EconomyService.lua - JANTUNG EKONOMI:
-- JANGAN PERNAH simpan uang di leaderstats atau client!
-- Simpan di server table + ProfileStore:
-- playerData = { Coins = 0, Gems = 0, Inventory = {} }

-- Setiap transaksi:
-- 1. Server cek ledger: if playerData.Coins < price then REJECT
-- 2. Server yang kurangi: playerData.Coins -= price (client tidak bisa manipulasi)
-- 3. Log transaksi ke DataStore untuk audit (siapa, kapan, berapa)
-- 4. Jika ada anomali (uang naik 1M dalam 1 detik tanpa source valid) -> FLAG & ROLLBACK
```

**Honeypot Trap (Advanced):**
- Buat RemoteEvent palsu `_HoneypotAdminGiveCoins` yang tidak pernah dipanggil game normal.
- Jika ada exploiter yang coba fire remote ini -> AUTO BAN. 100% akurat karena hanya exploiter yang tahu remote ini ada (dari scan exploit tool).

### LAYER 4: RATE LIMITING & BEHAVIORAL HEURISTICS
```lua
-- AntiCheatService.lua
-- Token Bucket per player:
local RATE_LIMITS = {
    HarvestPlant = { tokens = 5, refillPerSecond = 5 },
    BuySeed = { tokens = 10, refillPerSecond = 2 },
    StealAttempt = { tokens = 3, refillPerSecond = 0.05 }, -- max 3 steal per menit
    TradeRequest = { tokens = 5, refillPerSecond = 0.2 },
}

-- Behavioral Analyzer (background loop tiap 5 detik):
-- - Jika player harvest 100x dalam 10 detik tapi plant growth time = 60 detik -> IMPOSSIBLE -> FLAG
-- - Jika player income per menit > MAX_THEORETICAL (whale paling hoki sekalipun) -> FLAG
-- - Jika player teleport distance > WalkSpeed * timeElapsed + toleransi -> FLAG
-- - Jika player Steal success rate 100% dalam 50x (aimbot-like) -> FLAG investigasi

-- EvidenceLocker: simpan 200 flag terakhir per player
-- Auto action: WARN (3x) -> KICK -> TEMP BAN 1 hari -> PERMA BAN (via DataStore)
```

### LAYER 5: DATASTORE SECURITY & ANTI-DUPE
```lua
-- DataService.lua dengan ProfileStore:
-- - Session Locking: 1 player 1 server yang bisa write. Cegah dupe trade dengan hop server.
-- - Trade dupe prevention: Trade dilakukan dalam MemoryStore queue + lock inventory kedua player selama trade.
-- - Rollback on error: Jika DataStore save gagal, JANGAN kasih item. Better player complain "item hilang" 
--   daripada exploiter dupe 1M item.
-- - Versioning: Simpan DataVersion, jika data corrupt -> restore dari backup, bukan reset.
-- - Sanitize on load: Cek data player: jika Coins < 0 atau > 999_999_999 -> reset ke max valid + log.

-- MemoryStoreService untuk cross-server state:
-- - Global steal cooldown, Auction bids, Guild data
-- - SortedMap untuk leaderboard (bukan OrderedDataStore yang lambat)
```
